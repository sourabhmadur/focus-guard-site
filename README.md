# Focus Guard

Set a goal and a timer. Focus Guard checks the page you're on against your goal with a vision AI model you choose, and blocks distractions.

▶ [Watch the demo](https://www.youtube.com/watch?v=Sx-BEsisr3E)

## Install

1. Download [`focus-guard.zip`](https://czcrafferybtstvoensa.supabase.co/functions/v1/download?item=focus-guard) and unzip it.
2. Open `chrome://extensions`, turn on **Developer mode**, click **Load unpacked**, and select the unzipped `focus-guard` folder.
3. On the Settings page that opens, pick OpenAI or OpenRouter, paste your API key, press **Test connection**, then **Save**.
4. Click the Focus Guard toolbar icon, enter a goal, and press **Start**.

Each check is a small request on your own API account. Nothing is sent to the developer. See the [privacy policy](https://sourabhmadur.github.io/focus-guard-site/privacy-policy.html).

Questions or bugs: [open an issue](https://github.com/sourabhmadur/focus-guard-site/issues).
